# AcePass 产品与功能规格

## 1. 产品目标与明确范围

系统持续回答三个问题：接下来学什么最值得、当前卡在哪里、什么作答证据证明已经会做。学习证据优先于笔记数量和聊天次数。

用户已明确：**多个考试项目；选择、填空、判断、大题都要支持。** 一个项目对应一个备考目标，可以有多个科目；一个用户可以同时备考多个项目。考试科目未指定，不把数学、资格考试或某年度写成业务默认常量。

P0 是首个可真实使用版本；P1 增强分析与自动辅导；P2 完成复杂导入和严格考试验证。不能把 P1/P2 的能力标成首版已完成。

## 2. 范围矩阵

| 功能 | P0：可使用闭环 | P1：分析与辅导增强 | P2：迁移与考试验证 |
|---|---|---|---|
| 多考试项目 | 创建、编辑、归档、切换；多科目；独立大纲与评分规则 | 跨项目时间分配优化 | 多用户管理和受控内容共享按需新增 |
| 题型 | 单选、多选、判断、多空填空、大题；共享材料及子题 | 主观题 AI 估计评分、手写步骤识别确认 | 受限公式等价判分、复杂专业题型插件 |
| 导入 | 粘贴文字、手工录入、单题图片识别；原图与校对；手工组卷 | 原生文字 PDF 批量导入；答案页匹配候选 | 扫描 PDF、多栏、跨页、复杂表格公式批量解析 |
| 题库质量 | 答案来源与审核分离、版本、重复提示、发布/撤回 | 自动标签候选、批量审核、重判影响预览 | 生成变式的独立校验流水线 |
| 学习 | 作答、确定性/人工判分、按需 AI 讲解、错误原因候选 | 诊断追问、考点前置关系辅助补弱 | 自动生成且已验证的迁移训练 |
| 推荐与复习 | 简单可解释规则；基础覆盖配额；手工配对验证题；延迟题任务 | FSRS 记忆卡、可解释优先级排序、增强覆盖策略 | 按真实使用数据校准规则 |
| 考点与报告 | 手工维护考点/模板、基本作答证据与失分报告 | 最近五个完整周期统计、覆盖缺口、年度对比 | 封存家族、限时模拟、分层效果报告 |
| 测验隔离 | 家族、用途、暴露台账与过滤基础；独立验证模式 | 增强污染检查 | 正式限时考试与严格家族隔离验收 |

不做：自由行动多 Agent、微服务拆分、模型微调、社交班级、支付商城、学习积分游戏、预测通过率。没有真实考试规则时，使用标识清晰的演示规则，不能冒充考试官方规则。

## 3. 项目配置与多项目体验

首次使用先设置用户时区和每日总学习时间，再创建考试项目。项目填写：名称、目标日期（可空）、目标分数、科目、各科满分/及格线、所用大纲与教材版本、题型及计分规则、项目时间分配。项目创建后仍可调整，已使用的规则通过新版本调整。

全局首页显示所有进行中项目、到期任务和总时间；进入项目后，页面顶部始终显示项目/科目。项目切换使题库、报告、辅导上下文与缓存查询同步切换，不能只改变标题。

每日总预算默认 60 分钟，可修改。多个活动项目共享这 60 分钟，不能每个项目各生成 60 分钟。P0 用户指定比例，未指定则等分；活动项目按考试日期、再按创建时间形成基础顺序，同余数按用户当地日期轮换优先顺序。总时间小于项目数时部分项目轮换；连一道题都放不下的余额按数据契约重新分配或保留为空闲，页面说明本日未分配原因。归档项目保留历史、停止新任务，进行中的作答先完成或明确结束后才能归档。

项目内科目也是隔离边界：题目绑定一个科目及适用大纲版本；默认不跨项目或跨大纲复用学习状态。后续内容复制建立新项目身份与来源关联，不把 A 项目修订同步覆盖到 B。同一用户跨项目的已知复制/同源题保留内容谱系并查询既往暴露，不能换项目后重新声称“系统内未见”。

## 4. 页面和关键交互

| 页面 | P0 必须完成 | 关键状态 |
|---|---|---|
| 全局项目首页 | 项目列表、创建、切换、总预算分配 | 无项目、项目归档、日期已过但用户仍继续学习 |
| 今日学习 | 继续任务、到期复习、补弱和验证任务；解释推荐原因 | 无可用题、时间不足、待人工评分、任务过期 |
| 题库与导入 | 图片/文字入口、进度、校对、原始区域、版本与来源、筛选 | OCR 失败、缺图、答案冲突、重复候选、待发布 |
| 考点地图 | 树形科目/章节/考点、模板标签、证据详情 | 未诊断、缺题、待复核；P1 增加年度权重 |
| 刷题工作台 | 全部题型输入、保存草稿、提交、把握程度、提示和解析 | 提交中、网络失败、待人工评分、已辅助作答 |
| 错题与复习 | 按考点/错误原因/评分来源筛选；配对题及延迟验证 | 原因未知、题目撤回、答案变更后重判 |
| 报告 | P0 显示练习证据及已确认得分；P2 增加限时模拟 | 分数待确认、样本不足、存在污染、数据重算中 |

设置放在项目菜单和全局菜单，内部内容审核使用 Django Admin 加自定义校对页。未交付的入口可以标注“后续阶段”，不能展示虚构数据或可点但无结果的按钮。

桌面刷题工作台左侧为题目/作答、右侧为按需辅导；手机上下排列。大题有多行文本和多张图片，支持拍照文件选择、预览、删除未提交附件；手写内容在 OCR 未接入时显示原图，不伪造转写。原图旋转/裁剪功能可在 P1 增强，P0 至少准确显示原图及已识别区域。

草稿先本地短暂缓存并同步到服务端，以 `session_item` 和版本号防覆盖；显示“正在保存/已保存/保存失败”。已提交作答不可编辑，重做新建题项。切换项目不得把草稿附到另一项目。

## 5. 各题型的首版行为

| 题型代码 | 输入 | P0 判分 | 无法确定时 |
|---|---|---|---|
| `single_choice` | 选一个稳定选项 ID | 与可信答案 ID 比较 | 标准答案有争议则不判分 |
| `multiple_choice` | 多个稳定选项 ID | 完全匹配或配置的少选部分分；错选按规则 | 缺规则不猜测部分分 |
| `true_false` | 真/假，未选为 null | 布尔值比较，false 不等于漏答 | 同上 |
| `fill_blank` | 按空位 ID 输入；保存原文 | 逐空精确匹配/已配置文本归一化/数值容差 | 语义、单位、公式无法判断则该空待复核 |
| `constructed_response` | 文字、步骤、图片附件 | 按 rubric 逐评分点人工确认，可由本人自评 | 保持待评，不能记成 0 分 |
| `material` | 共享材料；子题采用上述题型 | 父题不计分，只累计叶子题 | 结构不完整进入校对 |

选择题的选项 ID 不随显示顺序变化。填空是否区分大小写、空格、全半角、单位和空位顺序都在答案规则里显式定义；不全局删除负号、标点或数学符号。仅“规则完备且权威规则明确视为错误”的答案可自动记错；无法覆盖的答案进入待复核。

人工评分显示“自评确认”或“复核确认”，与自动判分区别。操作者是答题者本人时，即使拥有管理员权限也只能记自评；复核确认要求另一位获授权评分者。自评只产生自评证据，不进入严格掌握或封存测验能力结论。P1 AI 只提供建议分、评分点依据、缺失证据，未确认时不能混入正式总分。多空填空或大题部分待评时，显示已确认分数和待评分值，不能强行生成完整百分比。

## 6. P0 学习闭环

1. 导入 A 题，核对题干、配图、答案、评分规则和考点后发布。
2. 在服务端创建练习题项，提交前默认不下发答案；practice 中用户明确请求完整讲解/答案时允许并记录辅助暴露，verification/mock_exam 禁止；用户作答并记录用时、把握程度。
3. 按题型自动或人工确认判分。证据不足时错误原因保持未知。
4. 用户按需获取提示、关键条件解释或完整讲解；记录实际下发的辅助内容。
5. 选择预先审核的 B 题验证同一知识点；可以同模板，但不把它称作严格家族隔离测验。
6. 生成至少 24 小时后的 C 题验证任务；没有合格 C 题时显示缺题并允许复习原题，原题仅记重复练习证据。
7. 今日任务、错题和考点状态使用真实证据更新，展示排除原因。

P0 的 B/C 题由用户维护或从已审核题库挑选，不依赖自动生成题。用户在校对中已看过 B/C 的答案时，仍可使用它们练习，但不能称作“系统内未见题”。

练习模式允许提交前请求提示、完整讲解或查看答案，记录辅助暴露；不强迫先提交空答案。验证模式只允许独立提交，整个验证结束前不返回正误、分数或评分点。若要辅导，先结束验证，再新建练习会话，并保留已发生的题目暴露。P2 考试模式同样禁止辅导，并由服务端执行截止时间。

## 7. 学习证据与产品表达

分别记录：本题重复熟练度、无提示表现、系统内首次接触题表现、陌生变式表现、延迟表现、限时表现。卡片记忆不是解题能力。

显示状态可为“未诊断、需要补基础、提示后能完成、可以独立完成、可以处理陌生变式、经过延迟验证”；每个状态必须能打开证据列表。“需要补基础”需要确认的诊断依据，不根据选错一次就推断。

初始严格验证规则：至少 3 道不同题独立正确，覆盖至少 2 种模板，其中一次在相关讲解/训练至少 24 小时后完成；需要限时的题符合配置时间。只使用可信答案、确认判分和满足暴露条件的作答。数据不足显示缺什么证据，不输出伪精确百分比。阈值是可配置产品假设，不是提分效果承诺。

近期失败或题目修正可使证据失效、状态降级；历史达到过的状态单独保留。自评证据、AI 估计和独立可验证证据分别展示。

## 8. 范围调整及未确认事项

相对原始建议有四项有意调整：多项目与全部题型提前到 P0；轻量推荐和延迟验证提前以形成闭环；向量检索后置到 P1；复杂 OCR、生成题和正式模拟考试放到 P2。原始建议的核心质量边界保留。

待配置而非待猜测：实际考试及科目、评分细则、是否倒扣、答案使用范围、真实资料、模型服务、部署地址。具体模型提供商按能力选择；“交给 DeepSeek 开发”不等于必须使用 DeepSeek 作为产品中的视觉或嵌入模型。
